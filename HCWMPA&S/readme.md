# How Computing Works - Modern Paradigms of Architecture & System  计算如何运作 – 架构与系统的现代范式

This is a course in Childen's Computer Center, Children's Palace of Chinese Welfare Institute.

这是中国福利会少年宫计算机活动中心的一个课程。

## Course Description  课程简介

Modern workloads are emerging in the AI era. The popular science course introduces some selective paradigms to demonstrate how the computer architecture and system enable and accelerate workloads. The understanding is deepened through many guided practices centered on two simple compute problems, one on scientific computing and the other on AI. As a very basic course, minimum prior knowledge on mathematics and programming is required.    

人工智能时代，计算机工作负载急剧涌现。这门科普课程精选了一些计算机架构和系统的范式，展示计算的运作和加速，并在攻略的指引下，通过对围绕两个贯穿始终的问题（一个来自于科学计算，另一个来自于人工智能）的实践，加深对这些范式的认识。

预备知识：由于该课程为基础的科普课程，在预备知识方面对学生的要求较低。希望学生具备数据类型、数组、分支、循环等编程概念的基本知识。倘若对Python编程语言和C/C++语言有所了解则更好，但这不是必须的。
